# YYJCPL Application Roadmap 2026

**Checked against the current app files: 29 October 2026**

## What this app is for

YYJCPL will connect people looking for work with companies that need staff. Candidates and recruiters will use the mobile app. YYJCPL staff will use a separate admin website.

## Work already in the app

- The basic mobile app, its navigation, and its shared design are in place.
- Sign-up, sign-in, and verification screens are present. Firebase sign-in code is also present.
- Candidate screens are available for profiles, jobs, applications, interviews, and resumes.
- Recruiter screens are available for company details, jobs, applicants, candidates, and interviews.
- Shared screens are available for notifications, settings, and support requests.
- The app has a few basic automated tests.

**Important:** A screen being present does not mean that it is connected to a working service. The app's server, live data, and full user journeys have not been verified in this project.

## Phase 1 — Project planning

**Status: Partly done**

The project has a written guide and a basic plan for candidate and recruiter journeys. The app also has a list of the information it expects from its server.

**Still to do:** Agree on the final features, who can use each feature, how the server will work, who will build it, and how the team will decide that each feature is finished.

## Phase 2 — App design and screens

**Status: In progress**

The app already has many candidate, recruiter, and sign-in screens. It also has shared colours, layouts, and buttons.

**Still to do:** Review the screens with the business team, confirm the final designs, and check that they work on small phones, large phones, and tablets.

## Phase 3 — Build the working app

**Status: In progress**

The mobile app screens and the code that will connect them to a server are present.

**Still to do:**

- Build and connect the server and database.
- Make sign-in stay active when a user closes and reopens the app.
- Let candidates save their profiles and resumes, find jobs, apply, and check application updates.
- Let recruiters manage their company, post jobs, review candidates, and schedule interviews.
- Build the separate staff website for reviewing companies, jobs, and complaints.
- Add file uploads and other services needed for the agreed first release.

## Phase 4 — Test and fix

**Status: Upcoming**

Some basic app tests exist. The full candidate and recruiter journeys have not yet been tested from start to finish.

**Still to do:** Test the app with real server data on different phones. Check sign-in, job applications, recruiter tools, privacy, accessibility, and what happens when the internet or server is unavailable. Fix serious problems before release.

## Phase 5 — Prepare to launch

**Status: Upcoming**

There is no evidence in this app project that it has been released.

**Still to do:** Prepare the final app builds, complete the app-store information and approvals, test with a small group of users, and set up help and monitoring. Release the app only after the team approves it.

## What users should be able to do

### Candidates

Create an account, fill in a profile, add a resume, find jobs, apply, and follow application and interview updates.

### Recruiters

Create a company profile, post jobs, review applicants, find suitable candidates, create a shortlist, and arrange interviews.

### YYJCPL staff

Use a separate website to review users and jobs, help with complaints, and manage the service. This website is not part of the current mobile app.

### Job types

The service may include full-time and part-time jobs, internships, fresher and experienced roles, campus and bulk hiring, remote work, placement services, and recruitment support.

## Other work for later

- Send useful updates to candidates, recruiters, and staff.
- Offer optional paid plans for recruiters and career support for candidates.
- Set up secure payments if paid plans are approved.
- Add resume uploads, profile pictures, and company logos.
- Add reports to help the business understand how the service is being used.
- Consider future features such as job recommendations and video interviews after the main service is working well.

## Target schedule

The dates below are targets, not confirmed promises. The schedule may change depending on when the server and staff website are ready.

- **October 2026:** Finish planning and review the app designs.
- **October–November 2026:** Connect the app to the server and finish the main candidate and recruiter journeys.
- **November–December 2026:** Test the full app and fix important problems.
- **December 2026:** Prepare for a possible launch, if testing and business approval are complete.
